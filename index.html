Export rules for new art

        
    
          
  1. viewBox 0 0 128 128, with matching width/height. A bigger box is not a bigger creature, just a coarser raster.
    2. 
          
  2. Faces +X (right), pivot at the box centre (64,64) — that is the point the spine solver places and rotates. Off-centre art needs a pivot override.
    3. 
          
  3. No external references. The rasteriser is a plain Image under a strict CSP: no <image href>, no external fonts, no cross-file <use>, no @import. Convert text to paths.
    4. 
          
  4. Delete the GUIDE layer from the template before exporting.
    5. 
          
  5. Keep the art inside the box with a few px of margin — the sheet cell clips.
    6. 
          
  6. Filenames must match the manifest: seg0.svg … segN.svg (walkers use body.svg).
